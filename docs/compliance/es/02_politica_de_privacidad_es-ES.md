## 2. Qué datos personales tratamos

## 6. Cómo usamos la IA

Las respuestas del chat las redacta un sistema de IA y se marcan como «Generado por IA». Antes de enviar el texto al proveedor, eliminamos automáticamente algunos datos personales identificables, como correos, teléfonos y direcciones con número de portal. Esto no puede capturarlo todo; por ejemplo, un nombre de persona dentro de una frase. Las imágenes y el audio se envían sin modificar. [Nota para la revisión: no afirmar que se filtra el historial clínico hasta resolver el punto 28 del registro.]

El asistente ofrece información general. No diagnostica, no receta y no sustituye a un veterinario. Véase nuestro Aviso sobre la IA.

No tomamos decisiones sobre usted basadas únicamente en un tratamiento automatizado que produzcan efectos jurídicos o le afecten significativamente de modo similar (art. 22 RGPD).
